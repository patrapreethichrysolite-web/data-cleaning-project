# Data Cleaning & Structural Validation Project

## Objective
The objective of this project is to clean and validate raw s data using Excel.

## Issues Found
- Duplicate records
- Missing values
- Inconsistent text formatting
- Invalid numerical values

## Cleaning Techniques Used
- Removed duplicates
- Filled missing values
- Standardized text formatting
- Validated data entries

## Tools Used
- Microsoft Excel
- GitHub

## Outcome
The dataset was transformed into a clean and reliable dataset suitable for analysis.
